# Clean Java Architecture & API Guidelines

Enforces project coding standards:
- Hexagonal Architecture (Ports and Adapters)
- Strongly typed serialization/deserialization for JSON and XML (JAXB / Jackson)
- Jakarta EE packages (`jakarta.*`)
- Internal message bus for domain events
- RESTful Web API with content negotiation (JSON/XML)
- Interactive OpenAPI / Swagger UI dev endpoint
- SQLite storage with Hibernate ORM (Jakarta Persistence)
- Google OAuth2 token authentication
